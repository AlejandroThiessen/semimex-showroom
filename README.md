# SemiMex — Showroom

Public design preview of the SemiMex showroom website.

**Website:** https://alejandrothiessen.github.io/semimex-showroom/

Includes the vehicle catalog, galleries, contact pages, and subtly rounded styling. Inventory availability and prices must be confirmed with SemiMex.

This repository contains only the static website export. GitHub Pages publishes the root of the main branch.
